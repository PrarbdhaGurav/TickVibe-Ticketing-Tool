# TickVibe – Ticketing Tool

A desktop-based Ticketing Tool developed using C#, ADO.NET, and SQL Server to manage and track support tickets.

## Technologies Used

* C#
* Windows Forms
* ADO.NET
* SQL Server
* SQL
* Visual Studio

## Key Features

* Ticket management and tracking
* Ticket status management
* Team Leader module
* Database connectivity using ADO.NET
* SQL Server integration

## Project Structure

* **TickVibe** – Main desktop application
* **TickVibeLib** – Class library containing application logic

## Getting Started

1. Clone or download this repository.
2. Open `TickVibe.sln` in Visual Studio.
3. Configure the SQL Server connection string for your local environment.
4. Set up the required database and tables.
5. Build and run the application.

## Database

The application uses Microsoft SQL Server. A database setup script can be added to this repository after removing any confidential or real user data.
